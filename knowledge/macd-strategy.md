# MACD 趋势顾问战法

> MACD 不是“金叉买、死叉卖”，而是交易系统最后一层的趋势确认与风险否决模块。

## 系统位置与优先级

常规战法排序固定为：`B1 > MACD 顾问 > 其他入场战法`。这里的“第二优先级”不代表 MACD 可以独立买入：

- B1 等上游模块负责产生入场触发。
- MACD 负责判断趋势资格、动能真实性与结构风险。
- MACD 可以确认或否决上游信号，但不能单独批准交易。
- 一旦触发硬否决，风险优先级提升为 `CRITICAL`，高于任何常规买入排序。

## 固定判断顺序

1. 先看 `macd_dif` 与零轴，确定大级别多空区间。
2. 再看价格、DIF 和柱体是否顺周期。
3. 再比较已确认摆动高低点，识别顶底背离。
4. 再识别金叉空、死叉多等交叉失败。
5. 最后与 B1、砖形图、突破、价格黄白线和 S1 等上游信号组合。

默认参数为 `12, 26, 9`，柱体使用 `2 × (DIF - DEA)`；至少预热 120 根 K 线后再输出正式信号。

## 四状态模型

| 状态 | 条件 | 含义 |
|------|------|------|
| `BULL_IMPULSE` | `DIF > 0, BAR > 0` | 多头区间继续推动 |
| `BULL_PULLBACK` | `DIF > 0, BAR < 0` | 多头内部调整，不可自动判熊 |
| `BEAR_REBOUND` | `DIF < 0, BAR > 0` | 空头内部反弹，不具备趋势做多资格 |
| `BEAR_IMPULSE` | `DIF < 0, BAR < 0` | 空头继续下跌 |

先看 DIF，再看柱体。红柱不等于完整多头，绿柱也不等于完整空头。

## 顺周期

用最近 5 根 K 线计算三项斜率：

```text
price_slope = slope(log(Close))
dif_slope   = slope(DIF / Close)
bar_slope   = slope(BAR / Close)
```

三项同时为正且当前为红柱，输出强顺周期上涨；三项同时为负且当前为绿柱，输出强顺周期下跌。顺周期只说明存在持续买卖推动，不能证明某个主力身份。

## 无未来函数背离

背离只比较相邻的已确认摆动点。默认 `left=3, right=3`，摆动点 `i` 必须等到 `i+3` 才能确认，信号不得回填到 `i`。

- 顶背离：价格第二高点创新高，归一化 DIF 第二高点降低。
- 底背离：价格第二低点创新低，归一化 DIF 第二低点抬高。
- 单独背离只预警，不直接反手。
- 连续背离累计 `divergence_count`，不能第一次背离后永久锁死。
- 顶背离与金叉空共振，升级为硬否决。

价格容差使用 `max(0.5 × ATR(14), Close × 0.5%)`，DIF 容差使用近 60 日归一化 DIF 标准差的 25%。这些是研究参数，必须做样本外验证。

## 金叉空与死叉多

普通金叉、死叉只描述状态变化，不单独生成买卖信号。

- 金叉空 A：DIF 在 DEA 下方逐步靠近，接近交叉后再次向下分离。
- 金叉空 B：短暂金叉后 3 根内重新跌回 DEA 下方，DIF 转弱或绿柱放大。
- 死叉多 A：DIF 在 DEA 上方逐步靠近，接近交叉后再次向上分离。
- 死叉多 B：短暂死叉后 3 根内重新站回 DEA 上方，DIF 转强或红柱放大。

`DIF > 0` 的死叉多是“空中加油”确认；`DIF < 0` 的死叉多只算空头反弹改善。

## 建仓候选状态机

```text
UNKNOWN
  -> IMPULSE_CANDIDATE
  -> ACCUMULATION_CONFIRMED

IMPULSE_CANDIDATE
  -> ONE_WAVE_RISK
  -> FAILED_IMPULSE
```

第一段价格、DIF、柱体同步上涨只能叫 `IMPULSE_CANDIDATE`。只有经历缩量回调、DIF 守住零轴、结构支撑未破，并在后续出现二次启动，才能标记 `ACCUMULATION_CONFIRMED`。

涨幅过度集中于 1 至 2 日、回调放量破位、顶背离、金叉空或 DIF 快速跌回零轴下方，会提高 `ONE_WAVE_RISK`；硬否决不受累计分保护。

## 决策规则

硬否决包括：

- 上游趋势做多信号出现，但 `DIF < 0`。
- 顶背离与金叉空同时出现。
- 关键支撑破位，同时 `DIF < 0` 且绿柱放大。

允许进入 `ENTRY_READY` 必须同时满足：上游信号存在、`DIF > 0`、无硬否决、无强顶背离。日线收盘生成的信号最早在下一交易日按可成交价格执行。

输出必须保留 `warning_codes` 和 `confirm_codes`，不得只给不可审计的总分。

## 回测底线

- 使用滚动训练、验证与样本外测试，不全样本调参。
- A 股计入佣金、印花税、滑点、涨跌停、停牌与 T+1；ETF 计入价差和冲击成本。
- 对比仅上游系统、加零轴过滤、加顺周期、加背离、加交叉失败五组消融结果。
- 分多头、震荡、空头环境，以及 ETF、大盘股、小盘股分别报告。

这套战法持续回答三个问题：当前有没有趋势做多资格，推动是否仍然真实，原交易依据是否已经失效。
